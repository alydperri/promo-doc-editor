# Reference — Folder Contract

## What this folder is
Stable evaluation criteria used during every critique session. Nothing here is modified at runtime.

## Contents

| File | Job |
|---|---|
| `rubric.md` | The evaluation criteria — 18 content rules (R1–R18) and 5 universal writing rules (W1–W5). Every critique finding must cite a rule from this file. |
| `section-guide.md` | What each section of a promotion document should accomplish. Use to confirm whether a section meets its intended purpose. |
| `writing-quality-checklist.md` | Verification sweep checklist, organized by quality dimension. Run after the critique pass to catch cross-cutting patterns the section-by-section pass can miss. |

## When it's read
During step 6 (critique pass) and step 7 (verification sweep) of the run contract in `CONTEXT.md`.
