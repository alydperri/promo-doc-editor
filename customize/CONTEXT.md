# Customize — Folder Contract

## What this folder is
Optional org-specific configuration. Fill in these files to unlock company-specific critique rules. The editor runs without them — it skips the rules that require this context and notes which ones were not assessed.

## Contents

| File | Fill it in to unlock |
|---|---|
| `company-values.md` | R6 — values alignment. The editor checks whether performance examples connect to your org's values vocabulary. |
| `leveling-guide.md` | R3, R7, R13 — criteria alignment. The editor checks whether the document evaluates against the right expectations for the proposed level and role. |

## How to use
1. Open the file.
2. Replace the template placeholders with your organization's actual content.
3. Save. The editor picks it up automatically on the next session.

No renaming required — the files are already named correctly.
