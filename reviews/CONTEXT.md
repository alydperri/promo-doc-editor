# Reviews — Folder Contract

## What this folder is
The output layer. One file per completed critique session — a human-readable, editable record of the critique.

## Contents
- `_template.md` — frontmatter structure and naming convention for session files
- One `.md` file per completed critique session

## Naming convention
`YYYY-MM-DD-[candidate-name]-[current-level]-to-[proposed-level]-v[N].md`

Example: `2026-07-21-maria-chen-l5-to-l6-v1.md`
